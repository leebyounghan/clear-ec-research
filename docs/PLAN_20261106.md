## Measurement rule

Every result is read the same way, so results can be compared and stacked.

| Item | Rule |
|---|---|
| Encoder training | Mean of the last five epochs, at least folds 0 and 4, paired with a matched reference. One fold or one seed decides nothing: within-run SD is 0.05 |
| Pass, new member | Two-fold mean <= -0.05, CI below 0, or added to the best pipeline <= -0.02, CI below 0 |
| Pass, correction on stored predictions | Five folds on top of the best pipeline: <= -0.01 on the mean, CI below 0, 4 of 5 folds, settings chosen inside training folds |
| Tools | `experiments/meta_ceiling_20261103/source/best_pipeline_20261106.py` for all reads; corrections saved in its format |
| Records | Gate written before running, in the lane folder `protocol.json`; result in the lane folder `REPORT.md` |
