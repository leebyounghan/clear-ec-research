## Diagnosis

The labels are a statistic of individual cells inside a technician ROI (17 % of the frame). Recipe A reduces the whole
frame to a texture statistic (std of patch tokens) and regresses on it. CD survives that mismatch. CV and HEX do not:
R2 0.46 and 0.36, prediction spread 63 % and 57 % of the label spread.
Predictions for a donor's two eyes correlate 0.78 (CV) and 0.76 (HEX), while their labels correlate 0.43 and 0.25.

- Not the limit: capacity (more freedom lowers train error to 7.26 and raises validation by 0.33), encoder strength (95-98 % of the error is shared with an unrelated model family), seeds (infinite seeds
  -0.024), domain bias (group offsets 1-3 % of the error), routing between existing models.
- Human annotation is ruled out by the PI. Supervision comes from public datasets, the 25 annotated images, self-training and, since 2026-11-05, the image-level labels read through a cell graph (geometry only; image values at the nodes memorise).
- Possibly irreducible, not measured on the whole data: the HEX floor of ~8.6 comes from 25 frames of one style, and CV has no floor estimate. Label-image disagreement in the top 1 % of CD errors is 0.22 pp of the final score.

## Assumption audit (2026-11-05)

On labels, inside that window: CV from points r 0.21 -> 0.44, CD 0.39 -> 0.57 |
| Window statistics add nothing beyond B | HEX residual fit, LOFO | **Wrong.** Three legible windows -0.032; whole frame -0.011; centre -0.006; hex6 alone 0; window position alone +0.016 |
| CD is closed: expert points reach only 7.2 % | Label / marker density, per image | **Unjustified.** Ratio 0.97-1.43, near 1 on clean sets and large where the marked set has gaps: the 7.2 % is mostly an estimator limit, not a noise floor |
| HEX floor 8.6 applies to the data | Markers vs label | From 25 frames of one style. On clean sets hex6 of the markers matches the label within 1-2 %: the label is a function of which cells were marked |
| ROI mismatch is the main cause | Phase-1 sees about the centre, recipe A the whole frame; quality-anchored crops (Phase-1 anchor_quality 9.09) do no better | Weak for pooling. Holds only for geometric statistics |
| One label process, one scale | Label CD x spacing^2 | CD = 1e6 / integer mean area. Sources differ by about 9 % in k at equal spacing (detector-based; not confirmed by FFT). Unimodal: no hidden magnification classes. k correlates 0.48 between fellow eyes, 0.08 between adjacent donors: donor-level, not session drift |
