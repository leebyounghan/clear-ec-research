# Order work by the share of the gap it can close

## Rule

Rank jobs by how much of the gap to V14 they can close (11-08: CV ~0.12, CD ~0.09, HEX ~0.04 if submission-1 test-minus-OOF gaps repeat); big levers first (new model family, new input signal, cross-lane member).
