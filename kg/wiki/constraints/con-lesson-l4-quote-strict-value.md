# L4: quote the strictly nested value with the as-computed value next to it

## Rule

Cue: any stack, chain or selection number. Lesson: choosing on reported rows was worth 0.006 (CV inner stretch), 0.010 (HEX chain step selection), 0.010 (cell-route feature-version choice). Gate: quote the strictly nested value with the as-computed value next to it.

## Notes

A pre-launch gate: before a new GPU direction, answer the cue in one line in the first RESULTS.tsv row. The gates decide how a number is read and quoted; they add no CI or minimum-effect threshold ([[con-no-statistical-gates]]). Adopted by [[dec-015-framework-revision-20261111]].
