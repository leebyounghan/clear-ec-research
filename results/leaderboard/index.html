실험 로그 템플릿

새 실험은 시작 전에 가설과 비교 조건을 적고, 종료 후 결과와 판단을 덧붙입니다. 원본 아이디어·manifest는 버전과 SHA로 고정합니다.

  1. 이전 실험 — 기준 실험 ID, 관측된 한계, 아직 불확실한 부분
  2. 이번 아이디어 — 기대 효과와 변경 변수, 버전별 아이디어 파일 위치
  3. 비교 계약 — split/이미지 수/seed/encoder/학습률/epoch/schedule/head, single·ensemble/TTA/보정
  4. 실행 증거 — 시작·종료 시각, 상태, 코드·manifest SHA, 실행 로그 위치
  5. 결과 — CD/CV/HEX/평균, 같은 조건 대조군 대비 Δ, audit 및 checkpoint
  6. 판단 — 관측과 해석을 구분, 유지·기각·재검증, 다음 실험

기존 실험 노트는 사후 재구성으로 표시했습니다. 작성되지 않은 과거 사전 가설을 만들어내지 않습니다.
