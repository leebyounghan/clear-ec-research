OOF-G1identity / scalar / regularized power / 작은 quality-conditioned residual model

log(p)를 보정하되 identity 방향 shrinkage. 예측3개와 사전에 고정한 소수 이미지 quality feature만 사용. 잔차 모델은 작은 ridge 또는 낮은 자유도 spline 하나로 제한; isotonic은 기존 부정적 대조. 같은 outer-train 안의 inner OOF로 fit하고 outer base도 outer-train만 학습해야 한다. 비용절감 탐색은 기존 OOF로 가능하지만 promotion 근거는 nested 재학습에서 얻는다.

동일 outer split의 uncorrected baseline 대비 CD/CV/HEX/mean 확인. 현재 단일 연구와 별도 후처리 트랙으로 기록; 기존 제출 보정 교체 금지
GREEN-G0green supervision 계약과 정합 감사

전체 train_green 파일 inventory와 25장 추출본 coverage 확인. 원본 overlay↔MHA image registration/scale, ROI/marker 위치, 빠진 점과 ROI 밖 unlabeled 영역 확인. image ID뿐 아니라 slide/exact connected group으로 split.

현재 fold4 train20만 학습 가능; heldout5 및 연결 그룹 배제. annotation 없는 영역을 background negative로 학습하지 않음
GREEN-G1pseudo-mask 없이 point/ROI auxiliary만 검증

고정된 CPDINO 회귀 baseline + 작은 center/density/ROI head. 우선 frozen backbone probe로 위치학습 가능성 확인 후 matched baseline 대 auxiliary A/B. ROI 내부 valid mask와 점 주변 positive loss를 사용하고 aux gradient 크기를 기록한다. 강도는 좁은 사전지정 범위; 같은 crop·geometry, photometric 변화만 분리.

heldout green 점 검출 precision/recall, count error, ROI localization 및 full1790 회귀평가. 5장만의 높은 분산·개발재사용 한계 명시. CV/HEX 개선은 독립 확인
GREEN-G2신뢰도 검증 후에만 teacher consistency 추가

G1 통과한 teacher의 heldout localization 품질로 threshold를 inner train에서 고정. train-only pool의 aligned view에서 confidence-masked consistency. supervised auxiliary와 consistency를 별도 arm으로 비교한다.

초기부터 noisy teacher를 강하게 따라가지 않음. green/validation 이미지 및 관련 그룹은 teacher 학습과 pseudo-pool에서 배제
GREEN-G3boundary pseudo-label은 마지막 순위

중심점/Voronoi/SAM mask를 정답이라 간주하지 않는다. 경계 오차·merge/split·세포 면적분포와 HEX 구현 정의를 별도 확인하고 충분한 근거가 있을 때만 mask self-training.

scalar gate만으로 전체9000장 pseudo-mask 생성 금지. 공식 baseline HEX IoU와 임상 6-neighbor 비율을 혼동하지 않음
